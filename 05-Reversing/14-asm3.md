### Descripción
What does asm3(0xed9f8013,0xb48f77b7,0xc3da54a7) return? Submit the flag as a hexadecimal value (starting with '0x'). NOTE: Your submission for this question will NOT be in the normal flag format. [Source](https://challenge-files.cylabacademy.net/library/9a3a6520d2dba9c49a0015b6fa49750bd32799492419bf5829073a2a027055d4/test.S)

### Solución
```
┌──(kali㉿kali)-[~]
└─$ cat test.S
asm3:
	<+0>:	push   ebp
	<+1>:	mov    ebp,esp
	<+3>:	xor    eax,eax
	<+5>:	mov    ah,BYTE PTR [ebp+0xb]
	<+8>:	shl    ax,0x10
	<+12>:	sub    al,BYTE PTR [ebp+0xc]
	<+15>:	add    ah,BYTE PTR [ebp+0xd]
	<+18>:	xor    ax,WORD PTR [ebp+0x12]
	<+22>:	nop
	<+23>:	pop    ebp
	<+24>:	ret

┌──(kali㉿kali)-[~]
└─$ # Análisis de la memoria en la pila (little-endian):
└─$ # arg1 = 0xed9f8013 -> [ebp+0x8]=13, [ebp+0x9]=80, [ebp+0xa]=9f, [ebp+0xb]=ed
└─$ # arg2 = 0xb48f77b7 -> [ebp+0xc]=b7, [ebp+0xd]=77, [ebp+0xe]=8f, [ebp+0xf]=b4
└─$ # arg3 = 0xc3da54a7 -> [ebp+0x10]=a7, [ebp+0x11]=54, [ebp+0x12]=da, [ebp+0x13]=c3

┌──(kali㉿kali)-[~]
└─$ # 1. xor eax, eax               -> eax = 0x00000000
└─$ # 2. mov ah, [ebp+0xb] (0xed)   -> ax  = 0xed00
└─$ # 3. shl ax, 0x10 (16 bits)     -> ax  = 0x0000 (todos los bits se desplazan fuera del registro de 16 bits)
└─$ # 4. sub al, [ebp+0xc] (0xb7)   -> al  = (0 - 0xb7) & 0xff = 0x49  => ax = 0x0049
└─$ # 5. add ah, [ebp+0xd] (0x77)   -> ah  = (0 + 0x77) = 0x77        => ax = 0x7749
└─$ # 6. xor ax, [ebp+0x12] (0xc3da)-> ax  = 0x7749 ^ 0xc3da = 0xb493

0xb493
```

### Notas adicionales
- Los parámetros se distribuyen en memoria en formato little-endian:
  - Primer argumento `0xed9f8013` en `[ebp+0x8..0xb]`. El byte en `[ebp+0xb]` es `0xed`.
  - Segundo argumento `0xb48f77b7` en `[ebp+0xc..0xf]`. El byte en `[ebp+0xc]` es `0xb7` y en `[ebp+0xd]` es `0x77`.
  - Tercer argumento `0xc3da54a7` en `[ebp+0x10..0x13]`. La palabra (WORD de 2 bytes) en `[ebp+0x12]` es `0xc3da`.
- Al realizar `shl ax, 0x10`, el registro `ax` (de 16 bits) se desplaza 16 posiciones hacia la izquierda, quedando completamente en `0x0000`.
- Posteriormente `al` se convierte en $(0 - \mathtt{0xb7}) \pmod{256} = \mathtt{0x49}$, y `ah` en $\mathtt{0x77}$, conformando `ax = 0x7749`.
- Finalmente, la operación XOR entre `0x7749` y `0xc3da` da como resultado `0xb493`.
