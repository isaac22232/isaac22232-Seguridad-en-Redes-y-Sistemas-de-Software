### Descripción
What does asm2(0x4,0x29) return? Submit the flag as a hexadecimal value (starting with '0x'). NOTE: Your submission for this question will NOT be in the normal flag format. [Source](https://challenge-files.cylabacademy.net/library/970db6f9114bc04f46705c691cb4b3c3f2a9631904e972a84e9ce8d29714d3c8/test.S)

### Solución
```
┌──(kali㉿kali)-[~]
└─$ cat "test (1).S"
asm2:
	<+0>:	push   ebp
	<+1>:	mov    ebp,esp
	<+3>:	sub    esp,0x10
	<+6>:	mov    eax,DWORD PTR [ebp+0xc]
	<+9>:	mov    DWORD PTR [ebp-0x4],eax
	<+12>:	mov    eax,DWORD PTR [ebp+0x8]
	<+15>:	mov    DWORD PTR [ebp-0x8],eax
	<+18>:	jmp    0x119c <asm2+31>
	<+20>:	add    DWORD PTR [ebp-0x4],0x1
	<+24>:	add    DWORD PTR [ebp-0x8],0x94
	<+31>:	cmp    DWORD PTR [ebp-0x8],0x38f0
	<+38>:	jle    0x1191 <asm2+20>
	<+40>:	mov    eax,DWORD PTR [ebp-0x4]
	<+43>:	leave
	<+44>:	ret

┌──(kali㉿kali)-[~]
└─$ python3 -c "
# ebp+0x8  = 0x4  -> [ebp-0x8]
# ebp+0xc  = 0x29 -> [ebp-0x4]
v4 = 0x29
v8 = 0x4
while v8 <= 0x38f0:
    v4 = (v4 + 1) & 0xffffffff
    v8 = (v8 + 0x94) & 0xffffffff
print(hex(v4))
"
0x8c
```

### Notas adicionales
- Los argumentos son recibidos en la pila:
  - `[ebp+0x8]` = primer argumento = `0x4` (almacenado en la variable local `[ebp-0x8]`).
  - `[ebp+0xc]` = segundo argumento = `0x29` (almacenado en la variable local `[ebp-0x4]`).
- La función ejecuta un bucle `while`:
  - En cada iteración incrementa `[ebp-0x4]` en `1` y `[ebp-0x8]` en `0x94` (148 decimal).
  - El bucle continúa mientras `[ebp-0x8] <= 0x38f0` (14576 decimal).
- Partiendo de `4` y dando pasos de `148`, el bucle se ejecuta 99 veces:
  $$4 + 99 \times 148 = 14656 > 14576$$
- La variable `[ebp-0x4]` pasa de `0x29` (41) a $41 + 99 = 140 = \mathtt{0x8c}$.
- El valor retornado en `eax` es `0x8c`.
