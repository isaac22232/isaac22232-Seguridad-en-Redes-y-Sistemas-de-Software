### Notas adicionales
Para controlar el comportamiento de los bots "buenos", los sitios web utilizan un archivo de texto llamado **`robots.txt`**. Este archivo funciona como un recepcionista que le dice a los robots qué partes del sitio tienen permiso para visitar y cuáles tienen prohibidas.

Con el comando curl le pasas un sitio web te muestra todo el html en la consola
